# EL6 / Electrode Factory — ML Predictive Maintenance (portfolio project)

Учебный pet-project для портфолио Data Scientist / ML Engineer.

## Важное ограничение

Данные в этом репозитории **синтетические**. Это не телеметрия ЭЛ6/НОВЭЗ и не описание реальных уставок или алгоритмов защиты конкретного оборудования.

Живой веб-поиск в этой сессии недоступен, поэтому параметры не выдаются за проверенные данные ЭЛ6. Проект использует правдоподобные учебные диапазоны для промышленного оборудования и участка обработки графитового электрода. Когда появятся реальные/публичные источники, диапазоны можно заменить на документированные.

## Бизнес-задача

Предсказать, возникнет ли перегрев оборудования в следующие 10 минут, чтобы оператор получил предупреждение заранее.

Важно: ML-модель в проекте **не управляет реальным станком и не заменяет штатную защиту/ПЛК**. Остановка оборудования в учебном проекте моделируется только как программное предупреждение/симуляция.

## ML-задача

Binary classification:

`overheat_next_10min = 1` — по текущей телеметрии есть риск перегрева в следующие 10 минут.

## План проекта

1. Сгенерировать синтетическую телеметрию.
2. Провести EDA.
3. Сделать feature engineering.
4. Обучить baseline-модель.
5. Оценить precision / recall / F1 / PR-AUC.
6. Сделать API на FastAPI.
7. Упаковать API в Docker.
8. Добавить MLflow, мониторинг и dashboard.

## Запуск первого этапа

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python src/generate_data.py
python src/train.py
```

После этого появится `models/model.joblib`.
